# 【マスタープラン】ソロアーティストHPフルカスタム制作

## ゴール
- 現行 https://www.taiseifukumoto.net/ (Wix) を廃止し、フルカスタムで作り直す
- **ベンチマーク（ryosukeyamada.com / nakajimakento.com）のクオリティに勝つ**
- 見やすく・わかりやすく・かっこよく、**ファンが増える**サイトにする

## 勝ち方（ベンチマークに勝てる4点）
1. **表示速度** — 大手制作のサイトは意外と重い。Lighthouseスコア90点以上を必達にし、体感で勝つ
2. **モバイル体験** — ファンの閲覧はほぼスマホ。スマホ設計を最優先にする
3. **更新の鮮度** — 大手サイトは更新が事務的。秘書経由で即日更新できる運用で「生きているサイト」にする
4. **導線設計** — SNS→HP→ライブ/FC/サブスクへの流れを計測しながら改善（大手は作りっぱなしが多い）

## 体制
- **えりんぎさん**：決める（デザイン方針・掲載内容）、出す（写真・テキスト素材）
- **秘書**：設計・コーディング・デプロイ・運用の実務すべて

## 技術構成（ベンチマークと同格のフルカスタム）
- Next.js 16 + Tailwind CSS 4（この作業リポジトリで開発）
- ホスティング：Vercel（無料枠で開始可・世界CDN配信＝CloudFront相当）
- 独自ドメイン接続（taiseifukumoto.net 継続 or 新ドメイン）
- 更新運用：えりんぎさんが秘書に指示 → 秘書がコード更新 → 自動デプロイ
