# Vercel 仮公開手順（えりんぎさん操作用）

所要約5分・無料。完了すると `〜.vercel.app` の限定URLが発行され、スマホから実物を確認できる。
以後は秘書がGitHubにプッシュするたび自動で最新版に更新される。

## 手順

1. **アカウント作成**
   - https://vercel.com/signup を開く
   - 「Continue with GitHub」を選び、GitHubアカウント（eeeringiii）でログイン・認可

2. **プロジェクト作成**
   - ダッシュボードで「Add New… → Project」
   - 「Import Git Repository」で `eeeringiii/project-1` を選ぶ
   - 一覧に出ない場合は「Adjust GitHub App Permissions」から project-1 へのアクセスを許可

3. **設定（ここが重要・2箇所）**
   - **Root Directory**：「Edit」を押して `taisei-site` を選択（サイト本体はこのフォルダ内のため）
   - そのほか（Framework: Next.js、Build設定）は自動検出のままでOK

4. **Deploy を押す**
   - ⚠️ 初回は失敗する可能性が高い（本番ブランチ=main にはまだ taisei-site が無いため）。失敗しても正常なので次へ

5. **ブランチの切り替え**
   - プロジェクトの「Settings → Git → Production Branch」を
     `claude/personal-ai-secretary-29x73a` に変更して保存
   - 「Deployments」タブ → 右上「Redeploy」(または Create Deployment) で再デプロイ

6. **完了**
   - 発行された `https://〜.vercel.app` のURLを秘書に共有

## 補足
- 恒久的には main ブランチへの統合（プルリクエスト）を行うのがきれい。ご希望があれば秘書がPR作成〜マージまで案内する
- 独自ドメイン接続は Phase 3 で。この仮URLのままファンに公開はしない
