# 初回面談 前後リマインド・メッセージ設計（L Message / エルメ）

- 作成日：2026-07-13
- 用途：**退職希望者**との初回面談の前後に、エルメの「リマインド配信」で自動送信するメッセージ一式
- 面談方法：**LINEの音声通話**（お時間になったらこちらから発信）
- トーン：落ち着いた敬語・真面目・安心感重視。絵文字は使わない。結論や決断を急がせない
- 前提：予約日時（面談日時）を基準に「◯日前・◯時間前」でトリガー。差し込みは〔 〕表記→エルメの差し込みタグ（%NM% 等）に置換して使用
- ゴール：**不安をやわらげ、無断キャンセルを防ぎ、面談後も安心して相談を続けられる状態をつくる**

---

## シナリオ全体像（送信タイミング）

| # | タイミング | トリガー設定の目安 | 目的 |
| --- | --- | --- | --- |
| ⓪ | 申込導線 | 友だち追加直後の案内 | 面談申込へ誘導 |
| ① | 予約完了直後 | 予約登録の即時 | 日時・通話方法・安心の一言を共有 |
| ② | 前日 | 面談の「1日前」18:00 | 想起・準備不要の明示 |
| ③ | 当日直前 | 面談の「1時間前」 | 発信方法の確認・静かな場所の案内 |
| ④ | 面談後（当日） | 面談の「2時間後」or 当日21:00 | お礼・今後の案内・継続サポートの明示 |
| ⑤ | 数日後フォロー | 面談の「3日後」10:00 | 未返信者へ寄り添い・質問受付 |

> エルメ設定メモ：⓪は自動応答/挨拶メッセージ、①は予約完了アクション、②〜⑤は「リマインド配信」で面談日時を基準に相対指定すると管理が楽です。

## ⓪ 申込導線（友だち追加直後などの案内）

```
はじめまして。ご登録ありがとうございます。

退職に関するお悩みやご状況を、まずは一度、落ち着いてお話しいただける初回面談をご用意しています。
面談はLINEの音声通話で行い、費用はかかりません。まだ気持ちが固まっていない段階でも大丈夫です。

「話を聞いてみたい」という気持ちだけで十分です。お気軽にお申し込みください。

▼お申し込みはこちら
〔予約フォーム / 予約ボタン〕
```

## ① 予約完了直後

```
〔お名前〕さん

このたびは面談のお申し込みをいただき、ありがとうございます。
ご予約の内容をお知らせします。

▼ご予約内容
・日時：〔面談日時〕
・方法：LINEの音声通話（お時間になりましたら、こちらから発信します）
・所要：約30〜45分

面談では、〔お名前〕さんの現在のご状況やお気持ちを丁寧にお伺いします。
無理に結論を出す場ではありませんので、どうぞ安心してお話しください。

ご都合が変わった場合は、このトークからいつでもご連絡いただけます。
当日はよろしくお願いいたします。
```

## ② 前日リマインド

```
〔お名前〕さん

明日の面談についてのご連絡です。

・日時：〔面談日時〕
・方法：LINEの音声通話（こちらから発信します）

事前のご準備は特に必要ありません。
気になっていることや伺っておきたい点があれば、お手元にメモしておいていただくとスムーズです。

明日、〔お名前〕さんのお話をお聞きできればと思います。
ご都合が変わった際は、このトークからお知らせください。
```

## ③ 当日直前リマインド（開始1時間前）

```
〔お名前〕さん

まもなく面談のお時間です。
・開始：〔面談時刻〕（およそ1時間後）

お時間になりましたら、こちらからLINEの音声通話を発信いたします。
通話しやすい静かな場所でお待ちいただけますと幸いです。

それでは、のちほどよろしくお願いいたします。
```

## ④ 面談後（当日）

```
〔お名前〕さん

本日は面談のお時間をいただき、ありがとうございました。
〔お名前〕さんのお気持ちやご状況をお聞かせいただけたこと、感謝しています。

▼このあとについて
・〔今後の進め方／必要な手続き／次回のご連絡時期 など〕

ご不明な点や、あとから思い浮かんだご質問があれば、このトークからお気軽にお寄せください。
引き続きサポートいたしますので、どうぞご安心ください。
```

## ⑤ 数日後フォロー（3日後・未返信者向け）

```
〔お名前〕さん

先日は面談にご参加いただき、ありがとうございました。
その後、ご不安な点や迷っていることはございませんか。

「もう少し詳しく聞きたい」「この点が心配」など、どんな小さなことでも構いません。
〔お名前〕さんが納得したうえで次の一歩を選べるよう、丁寧にお手伝いします。

お返事はいつでも大丈夫です。このトークからお気軽にご連絡ください。
```

## 運用メモ・改善余地
- **絵文字は使わない**方針。デリケートな相談のため、軽さより誠実さを優先
- ③直前リマインドは**接続・無断キャンセル対策に最も効く**ため必ず入れる
- ④の「このあとについて」は**1通に1つの案内**に絞ると、相手の負担が減り返信率が上がる
- ⑤は答えを急がせないトーンを維持。「お返事はいつでも大丈夫」を必ず添える
- 既に手続きに進んだ方へ⑤が届かないよう、エルメの**タグ/条件分岐で除外**設定を推奨
- 必要に応じて①や⓪に**「秘密は厳守します」「ご相談内容が外部に漏れることはありません」**の一文を足すと安心感が増す

## 次の確認事項（えりんぎさんへ）
1. ①または⓪に**秘密厳守の一文**を入れますか？（退職相談では安心材料として効果的）
2. 面談は**無料**の前提で書きました。有料や条件がある場合は⓪を調整します
3. ④の「このあとについて」に入れる**標準の次アクション**（例：必要書類の案内／次回連絡時期）を決めておくと運用が固まります
