# 初回面談 前後リマインド・メッセージ設計（L Message / エルメ）

- 作成日：2026-07-13
- 用途：ライバー志望者との**初回面談**の前後に、エルメの「リマインド配信」で自動送信するメッセージ一式
- 前提：予約日時（面談日時）を基準に「◯日前・◯時間前」でトリガー。差し込みは〔 〕表記→エルメの差し込みタグ（%NM% 等）に置換して使用
- ゴール：**無断キャンセルを減らす／当日の接続トラブルを防ぐ／面談後に次アクションへつなげる**

---

## シナリオ全体像（送信タイミング）

| # | タイミング | トリガー設定の目安 | 目的 |
| --- | --- | --- | --- |
| ① | 予約完了直後 | 予約登録の即時 | お礼・日時/URL・準備物・変更連絡先を確定共有 |
| ② | 前日 | 面談の「1日前」18:00 | 明日ある旨の想起・URL再掲 |
| ③ | 当日直前 | 面談の「1時間前」 | 接続確認・直前の後押し |
| ④ | 面談後（当日） | 面談の「2時間後」or 当日21:00 | お礼・要点・次アクション案内 |
| ⑤ | 数日後フォロー | 面談の「3日後」10:00 | 未返信者の背中を押す・質問受付 |

> エルメ設定メモ：①はリマインドではなく予約完了アクション（自動応答/シナリオ）に、②〜⑤は「リマインド配信」で面談日時を基準に相対指定すると管理が楽です。

---

## ① 予約完了直後

```
〔お名前〕さん、面談のご予約ありがとうございます！

▼ご予約内容
・日時：〔面談日時〕
・場所：〔Zoom / 対面住所〕
・所要：約30〜45分

当日はリラックスしてお話しできればと思っています😊
「配信でこうなりたい」という理想や、不安なことがあれば当日ぜひ聞かせてください。

▼お願い
・通信環境の良い静かな場所からのご参加がおすすめです
・日程変更・キャンセルはこちらのトークからご連絡ください

それでは当日お会いできるのを楽しみにしています！
```

## ② 前日リマインド

```
〔お名前〕さん、こんばんは！
明日の面談のリマインドです✨

▼明日のご予定
・日時：〔面談日時〕
・場所：〔Zoom URL / 対面住所〕

事前準備は特に不要です。気になることをメモしておくと当日スムーズです📝
明日、〔お名前〕さんとお話しできるのを楽しみにしています！

※ご都合が変わった場合は、このトークからお早めにご連絡ください。
```

## ③ 当日直前リマインド（開始1時間前）

```
〔お名前〕さん、まもなく面談のお時間です！

・開始：〔面談時刻〕（あと1時間ほど）
・入室：〔Zoom URL〕

お時間になりましたら上記URLからご参加ください。
接続が不安な場合は、少し早めに一度お試しいただくと安心です。
それではのちほど、よろしくお願いします😊
```

## ④ 面談後（当日）

```
〔お名前〕さん、本日は面談のお時間をいただきありがとうございました！
〔お名前〕さんの〔当日の印象・目標を一言〕、とても印象に残っています。

▼このあとの流れ
・〔次アクション：合否連絡／契約手続き／体験配信の日程調整 など〕
・〔期限や次回日程があれば記載〕

疑問や、あとから出てきた質問があればこのトークにお気軽にどうぞ。
本日はありがとうございました✨
```

## ⑤ 数日後フォロー（3日後・未返信者向け）

```
〔お名前〕さん、こんにちは！先日は面談ありがとうございました😊

その後、気になる点や迷っていることはありませんか？
「もう少し話を聞きたい」「ここが不安」など、どんな小さなことでも大丈夫です。
〔お名前〕さんが納得して一歩を踏み出せるよう、しっかりサポートします。

▼次の一歩
・〔体験配信 / 再面談 / 契約手続き などの導線を1つ提示〕

お返事お待ちしています！
```

## 運用メモ・改善余地
- **絵文字**は事務所トーンに合わせて増減。硬めが良ければ削減可
- ③直前リマインドは**接続トラブル削減に最も効く**ため、対面の場合も「集合場所・目印」に差し替えて必ず入れる
- ④の次アクションは**1通に1つだけ**にすると返信率が上がる
- ⑤は「面談で契約に至らなかった層」への追客。既に契約済みの人に届かないよう、エルメの**タグ/条件分岐で除外**設定を推奨
- A/Bで試すなら、まず②前日と③直前の**送信時刻**を動かして反応を見るのが効果的

## 次の確認事項（えりんぎさんへ）
1. 面談対象は **ライバー志望者**の想定で合っていますか？（副業アーティスト側なら文面トーンを調整します）
2. 面談は **Zoom / 対面** どちら中心ですか？（URL or 集合場所で②③を確定）
3. 事務所として入れたい**固定の一言（キャッチ・締めの挨拶）**があれば反映します
