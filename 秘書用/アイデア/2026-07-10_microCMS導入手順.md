# microCMS 導入手順（スタッフ入稿画面の準備）

スタッフが記事（NEWS等）をブラウザから入稿できるようにするための準備。
**えりんぎさんに操作いただくのはアカウント作成まで**で、接続・実装は秘書が行う。

## えりんぎさんにお願いする操作（約5分・無料）

1. https://microcms.io/ にアクセスし「無料で始める」からアカウント登録
2. サービス（プロジェクト）を作成
   - サービス名：`taisei-official`（任意）
   - サービスID：そのままでOK（あとで秘書に共有）
3. APIを1つ作成
   - API名：`news` ／ 型：**リスト形式**
   - フィールドは仮でOK（あとで秘書が設計案を渡す）
4. 「サービス設定 → APIキー」画面を開き、**APIキー（GET権限）を秘書に共有**
   - 共有はチャットに貼らず、Vercelの環境変数に直接入れる方法を秘書が案内する

## 秘書側で行うこと（共有を受けたら）

- [ ] newsスキーマ設計（date / category / title / body / thumbnail）を反映
- [ ] Next.js側を lib/content.ts のローカルデータ → microCMS API取得に切り替え
- [ ] 入稿→自動反映（Webhook→Vercel再ビルド）の接続
- [ ] スタッフ向け「入稿マニュアル」1枚を作成

## 費用
- Hobbyプラン：0円（API 3個・転送量制限内）。個人アーティスト公式の規模なら無料枠で十分
- 超えたら Team プラン（月5,390円〜）だが、当面不要の見込み

## 運用イメージ
- NEWS更新：スタッフが microCMS 管理画面から入稿 → 数分で自動反映
- ページ追加・デザイン変更：えりんぎさんが秘書に指示
