# 推しコア（OSHICOA 16）本体の公開手順（えりんぎさん操作用）

所要約5分・無料。完了すると `〜.vercel.app` のURLが発行され、推しコア本体（ヲタク生態診断）がネット公開される。
**HP（`project-1-zeta-sooty.vercel.app` ＝ taisei-site）とは別プロジェクト**として立てる。同じリポジトリを使うが、見ているフォルダが違うだけなので互いに影響しない。

## 前提（確認済み）
- 推しコア本体はリポジトリの**ルート直下**（`app/` `data/`）にあり、**mainブランチに載っている**
- ローカルで `npm run build` 成功（全31ページ生成OK・2026-07-25 秘書確認済み）
- 診断はブラウザ内で完結するため、**公開に必須の環境変数はなし**

## 手順（Vercel）

1. **新規プロジェクト作成**
   - https://vercel.com/dashboard を開く（GitHub: eeeringiii でログイン済みのはず）
   - 「Add New… → Project」

2. **同じリポジトリをもう一度Import**
   - 「Import Git Repository」で `eeeringiii/project-1` を選ぶ（HPで使ったのと同じリポジトリでOK）

3. **設定（HPとの唯一の違い＝ここだけ注意）**
   - **Root Directory：ルートのまま（`./`）**。HPの時は `taisei-site` を選んだが、今回は**何も選ばず（変更せず）リポジトリ直下のまま**にする
   - **Project Name：`oshicoa16`** など、HPと区別できる名前にする（発行URLがこの名前になる）
   - Framework: Next.js／Build Command `npm run build` は自動検出のままでOK

4. **Production Branch：`main`（デフォルトのまま）**
   - 推しコア本体はmainに載っているので、**初回から成功する**（HPの時のような初回失敗は起きない）

5. **Deploy を押す**
   - 数十秒で `https://oshicoa16-〜.vercel.app` が発行される

6. **発行URLを秘書に共有**
   - このURLを秘書に伝えてください（次のステップで設定に反映します）

## 発行後（秘書が対応・任意だが推奨）

発行URLが分かったら、共有・OG画像・sitemap を正しいURLに合わせるため、環境変数を1つ設定して再デプロイする：

- **Settings → Environment Variables** に追加
  - `NEXT_PUBLIC_SITE_URL` = 発行された `https://oshicoa16-〜.vercel.app`（末尾スラッシュなし）
- **Deployments → Redeploy** で再デプロイ

これでX/LINE共有リンクや動的OG画像が本番URL基準になる。独自ドメイン接続時は、この変数を差し替えるだけでよい。

## 補足
- **HPとは完全に独立**：`project-1-zeta-sooty`（HP）と `oshicoa16`（推しコア）は別プロジェクト。片方をいじってももう片方に影響なし。同じリポジトリを2つのRoot Directoryで見ているだけ
- **自動デプロイ**：以後、秘書がmainを更新するたびに推しコアも自動で最新版に更新される
- **ANTHROPIC_API_KEY は不要**：`/api/analyze-food` `/api/feedback` は食事分析の実験用エンドポイントで診断とは無関係。診断機能だけなら未設定でOK（それらを使う場合のみ後から追加）
- 独自ドメイン接続は後フェーズで。この仮URLのままファンに広く公開する前に、README「仮データ」節（能力値・割合・相性文）の実測差し替えを検討
