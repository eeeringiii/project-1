# 広報・プレスリリース担当 — 解禁告知テンプレ（初版）

作成: 2026-07-14 ／ 担当: 広報・プレスリリース担当（メディア・PR部）
用途: 出演・リリース等の「解禁情報」を、各媒体へ同じ品質・正しい順序で告知するためのテンプレ集。

---

## 1. 解禁の基本ルール

1. **解禁時刻より前に一切出さない**（下書きは事前作成、公開は時刻厳守）
2. 出す順序は原則 **HP NEWS → X → Instagram →（必要なら）FC先行で事前予告**
3. 事実関係（日時・タイトル・表記）は必ず一次情報（先方資料）と突き合わせる
4. タイアップ・広告案件は **PR表記のルール確認を先に**（タイアップ担当と連携）

## 2. テンプレ: HP NEWS

```
【カテゴリ: MEDIA / RELEASE / LIVE / INFO】
タイトル: 〈媒体名〉「〈番組・作品名〉」出演決定のお知らせ

本文:
〈アーティスト名〉が〈媒体名〉「〈番組・作品名〉」に出演することが決定しました。

■ 放送/配信日時: YYYY年MM月DD日（曜）HH:MM〜
■ 媒体: 〈局・サービス名〉
■ 詳細: 〈公式URL〉

ぜひご覧ください。
```

## 3. テンプレ: X（解禁ポスト）

```
📢 解禁情報

〈アーティスト名〉が「〈番組・作品名〉」に出演します！

🗓 YYYY.MM.DD（曜）HH:MM〜
📺 〈媒体名〉

詳細はこちら → 〈HP NEWSのURL〉

#〈アーティスト名〉 #〈番組ハッシュタグ〉
```

- 140字を超える場合は詳細をHPへ誘導して短くする
- 画像は解禁素材の使用可否を確認してから添付

## 4. テンプレ: Instagram（フィード/ストーリーズ）

- フィード: 解禁素材1枚＋キャプションはX文面をベースに絵文字控えめで
- ストーリーズ: 「詳しくはハイライト/リンクへ」導線。24時間後にハイライト保存

## 5. 解禁チェックリスト（毎回コピーして使う）

- [ ] 解禁日時・掲載可能素材を先方資料で確認した
- [ ] HP NEWS 下書き作成（カテゴリ・日時・URL確認）
- [ ] X 下書き作成（ハッシュタグ・リンク確認）
- [ ] Instagram 下書き作成（素材の使用許諾確認）
- [ ] 公開後、各リンクの動作確認
- [ ] 出演情報をTV・出演管理担当の一覧に追記
