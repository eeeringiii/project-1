# イーオン ショート動画 台本9本（Instagram Reels / TikTok / YouTube Shorts）

作成日：2026-08-03
形式：トーク（掛け合い）形式／尺 15〜30秒／縦9:16

---

## シリーズ設計

| 項目 | 内容 |
| --- | --- |
| 登場人物 | **パパ**（英語ネイティブ・日本語は流暢だが時々つまる）／**ママ**（日本人）／**子**（3歳） |
| 立ち位置 | パパが「英語の視点」、ママが「日本の当たり前」を担当。**どちらも正解にしない**のがキモ |
| トーン | 教える動画にしない。夫婦の雑談が結果的に英語の学びになる |
| 落とし方 | オチ＝笑い or 「たしかに」。英語フレーズはテロップで置くだけ、説教しない |
| 尺の目安 | セリフ合計 100〜140字（＝約20秒）。**書いたら必ず声に出して計測** |

### 共通フォーマット（全本共通）

1. **0〜2秒＝フック**：説明ゼロで、いきなり変なセリフから入る
2. **2〜15秒＝掛け合い**：1ターン1行、長ゼリフ禁止
3. **15〜20秒＝オチ**：ママのツッコミで終わる
4. **最後の1.5秒＝テロップ締め**（音声なし・静止テロップ）

### 共通の締めテロップ（差し替え可）

```
言いたいのに、英語が出てこない。
――イーオン
```

> ※ロゴ／キャッチは実際のブランドガイドに合わせて差し替えてください。

### 注意メモ

- **「パパの国」は実際の出身国に差し替え**（#2のみ日米比較のため「アメリカ」で固定）
- パパの日本語は「カタコト」にしない。**流暢だけど時々単語が出てこない**のがリアルで好感度が高い
- 子どものセリフは台本どおりに言わせない。**同じ意味のことを言ったテイクを採用**する

### おすすめ投稿順（夏休み期間中に週2〜3本）

`#1 → #4 → #6 → #2 → #9 → #5 → #8 → #7 → #3`

理由：#1は最もバズりやすい（子ども×命名）ので先頭。#4「宿題ゼロ」はコメントが伸びる論争型なので早め。ラジオ体操(#3)は共感が渋いので後半。

## 撮影・編集の共通メモ

- **音**：最初の1秒に必ず音の情報を置く（セミ、ドサッ、花火）。無音スタートは離脱する
- **カット**：掛け合いはジャンプカットで詰める。間を0.2秒残すと会話に聞こえる
- **テロップ**：英語は大きく・日本語は小さく。**英語を主役に置く**とアカウントの主題がブレない
- **字幕**：全編に焼き込み字幕。TikTok/Reelsは無音再生が前提
- **サムネ（YouTube Shorts用）**：オチのセリフではなく**フックのセリフ**を置く
- **横展開**：同じ台本でパパ／ママを入れ替えた「逆パターン」も撮れる（例：ママが英語で説明して詰まる）
