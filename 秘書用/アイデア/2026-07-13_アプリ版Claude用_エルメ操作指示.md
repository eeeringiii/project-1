# アプリ版Claude（Computer Use）への指示テンプレート — エルメ操作

- 作成日：2026-07-13
- 使い方：下の【依頼文】をコピーして、Macで動くアプリ版Claude（画面を見て操作できるもの）に貼る
- 前提：先に Google Chrome で該当の操作画面を開いておく
- 安全：`保存`は押してよいが、`配信ON`・`公開`など後戻りしにくい操作は「実行前に確認して」と伝える運用にする

---

## 指示①：ファネルタグ11件を作成

**先にやること**：Chromeで `https://step.lme.jp` にログイン →「データ管理」→「タグ管理」画面を開く

**【依頼文（ここからコピー）】**

```
L Message（エルメ）のタグ管理画面を開いています。以下の11個のタグを新規作成して保存してください。

1. F1_友だち追加
2. F2_予約ページ閲覧
3. F3_予約完了
4. F4_面談実施
5. F5_手続き中
6. F6_成約
7. F9_離脱_無反応
8. F9_キャンセル
9. F9_無断欠席
10. F9_対象外
11. 制御_予約済

手順の目安：
- 「＋新規作成」を押す
- タグ名の入力欄に1件目を入力
- 「タグを追加」で入力欄を増やし、2件目以降を順に入力（全部で11欄）
- 11件すべて入力し、誤字がないか確認
- 「保存」を押す

注意：
- 既存の「予約済み」「キャンセル」タグは触らない（そのまま残す）
- 保存後、タグ一覧に11件が追加されているか確認して報告して
```

## 指示②（次工程の例）：予約完了アクションにタグを紐づけ

※タグ作成が終わってから使う。画面：「カレンダー予約」→ 該当予約 → 予約完了時アクション

**【依頼文（ここからコピー）】**

```
エルメのカレンダー予約「退職相談 初回面談」の、予約完了時のアクション設定を開いています。
予約が完了したら、その友だちに次のタグ操作を自動で行う設定にしてください。
- タグ「F3_予約完了」を付ける
- タグ「制御_予約済」を付ける
- タグ「F2_予約ページ閲覧」が付いていれば外す
設定できたら保存して、内容を報告して。
```

---

## コツ
- 1つの依頼につき1画面・1タスクにすると、アプリ版Claudeが迷わず正確に動く
- 実行後は必ず「何をしたか報告して」と付ける → 結果を確認できる
- うまくいかない時は、画面のスクショをこちら（秘書）に見せてくれれば、依頼文を調整する
