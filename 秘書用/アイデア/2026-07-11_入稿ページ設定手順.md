# NEWS入稿ページ（/studio）有効化手順（えりんぎさん操作用）

入稿ページ本体はサイトに組み込み済み（https://project-1-zeta-sooty.vercel.app/studio ）。
有効化には**秘密情報2つをVercelに登録する**必要があり、これはアカウント所有者のえりんぎさんにしかできない。所要約5分。

## ① GitHubでトークンを発行する（入稿→サイト反映の鍵）

1. https://github.com/settings/personal-access-tokens/new を開く（eeeringiiiでログイン状態で）
2. 次のとおり設定：
   - Token name：`taisei-studio`
   - Expiration：**1年後**（切れたら再発行が必要。期限が来たら秘書がリマインド）
   - Repository access：**Only select repositories** → `eeeringiii/project-1` を選択
   - Permissions → Repository permissions → **Contents** を **Read and write** に（他は触らない）
3. 「Generate token」→ 表示された `github_pat_...` を**その場でコピー**（後から見られません）

## ② Vercelに登録する

1. Vercelの project-1 → **Settings → Environment Variables**
2. 次の2つを追加（EnvironmentはすべてONのままでOK）：
   - Key `GITHUB_CONTENT_TOKEN` ／ Value：①でコピーしたトークン
   - Key `STUDIO_PASSWORD` ／ Value：**担当者に共有する公開パスワード**（自由に決める。例：長めの日本語ローマ字＋数字）
3. 保存後、**Deployments → 最新 → … → Redeploy**（環境変数は再デプロイで反映）

## ③ 動作確認

- /studio を開き、テスト記事（タイトルに「テスト」と入れる）を公開 → 約2分後にNEWSへ出れば成功
- テスト記事の削除は秘書に「さっきのテスト消して」でOK

## 担当者への共有物
- 入稿ページURL：https://project-1-zeta-sooty.vercel.app/studio （独自ドメイン後は変更）
- 公開パスワード（②で決めたもの）
- 入稿マニュアル：`秘書用/アイデア/2026-07-11_入稿マニュアル.md`

## セキュリティのメモ
- パスワードを知る人だけが公開可能。漏れた場合はVercelの `STUDIO_PASSWORD` を変えるだけで即無効化できる
- トークンは project-1 の内容編集のみ可能な最小権限。Vercel外には保存されない
