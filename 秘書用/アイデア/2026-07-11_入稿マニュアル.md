# サイト入稿マニュアル（担当者向け・1枚）

## 用意するもの
- 入稿ページのURL（管理者から共有）
- 公開パスワード（管理者から共有）

## 基本の流れ
1. 入稿ページをブラウザで開く（スマホでもPCでも可）
2. **最初に、上部の欄へ公開パスワードを入力**（全タブ共通）
3. 更新したい内容のタブを選ぶ
4. 入力して公開ボタンを押す →「受け付けました」と出たら完了
5. **約2分後**にサイトへ自動で反映されます

## タブごとにできること

| タブ | できること |
| --- | --- |
| **NEWS** | お知らせ記事の公開（日時指定の予約公開も可）。**写真も3枚まで添付でき、本文の下に表示されます** |
| **リリース** | CD・配信作品の追加/削除。配信リンク・MVリンク・ジャケット写真も登録可 |
| **LIVE** | 公演・イベントの追加/削除。チケット受付期間を入れると期間中は自動で「受付中」表示＋申込ボタンが出ます |
| **MOVIE** | 動画の追加/削除。YouTubeのURLを貼るだけでサイトに埋め込まれます |
| **写真** | トップの大きな写真（アー写）／プロフィール写真の差し替え。スマホの写真そのままでOK（自動で軽量化） |
| **設定** | キャッチコピー・サイト紹介文・流れるテロップ・SNSとファンクラブのリンク・プロフィール文の変更 |

## よくある質問
- **内容を修正したい** → リリース/LIVE/MOVIEは「削除→追加し直し」。NEWSの修正と設定・写真の戻しは管理者（えりんぎさん）へ
- **「パスワードが違います」と出る** → 全角/半角・前後の空白を確認
- **押した直後にサイトに出ない** → 反映まで約2分かかります。少し待って再読み込みを
- **NEWSの予約を取り消したい／時間を変えたい** → 管理者へ連絡。公開前ならいつでも変更できます
- **写真がアップロードできない** → 通信環境を確認のうえ再試行。続く場合は管理者へ
