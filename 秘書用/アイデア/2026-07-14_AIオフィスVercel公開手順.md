# AIオフィス（/office）をVercelで常設URL化する手順

作成: 2026-07-14 ／ 対象: このリポジトリのルートNext.jsアプリ（`app/` 配下）
所要: 初回 約10分（えりんぎさんの操作が必要なのはVercelログインとリポジトリ接続のみ）

---

## 完成イメージ

- `https://〇〇.vercel.app/office` … ダッシュボード
- `https://〇〇.vercel.app/office/chart` … 組織図
- ブランチにプッシュするたび自動で最新化（日報・タスクの更新も反映）
- チーム限定: パスワード入力しないと開けない（後述のBasic認証）

## 手順

### 1. Vercelにログイン
https://vercel.com にGitHubアカウントでログイン（無料のHobbyプランでOK）

### 2. リポジトリを接続
1. 「Add New… → Project」
2. `eeeringiii/project-1` を Import
3. Framework Preset: **Next.js**（自動検出される）
4. Root Directory: **そのまま（リポジトリ直下）**
   - ⚠️ `taisei-site/` を選ばないこと（あちらはHP用の別プロジェクト）
5. Deploy を押す

### 3. チーム限定のパスワードを設定
1. Vercelのプロジェクト → Settings → Environment Variables
2. `OFFICE_PASSWORD` という名前で、チームに配る合言葉を設定（例: 長めのランダム文字列）
3. 再デプロイ（Deployments → 最新 → Redeploy）

→ 以降 `/office` を開くとユーザー名/パスワード入力が出る。
   **ユーザー名は何でもよい**（team 等）。パスワードだけ照合される。
   ローカル開発では `OFFICE_PASSWORD` を設定していないので、そのまま開ける。

### 4. チームへの共有
- URLと合言葉をセットで共有（合言葉はDM等、URLと別経路が望ましい）
- 合言葉を変えたくなったら環境変数を更新して再デプロイするだけ

## 運用メモ

- ダッシュボードの中身の更新 = このリポジトリの更新（`app/office/data.ts` や `秘書用/`）→ push で自動反映
- 独自ドメイン（例: office.〇〇.com）を割り当てたくなったら Vercel の Domains 設定から可能
- ルートの `/`（フードトラッカー）も同時に公開される点に注意。隠したければ次の改修で `/` を `/office` にリダイレクト可能（秘書に指示すればすぐやります）
