# 新サイト サイトマップと導線設計

## サイトマップ（現行8区画 → 7ページに再編）

```
/            TOP（ヒーロー／最新NEWS／RELEASE／MOVIE／LIVE／SNS）
├ /news        ニュース一覧 → /news/記事
│              ※現行の NEWS と INFORMATION はここに一本化
├ /profile     プロフィール（アー写・経歴・受賞歴）
├ /discography ディスコグラフィ → 作品詳細（配信リンク付き）
├ /movie       MV・映像（YouTube埋め込み）
├ /live        ライブ・イベント（現行 SCHEDULE を統合）
├ /contact     ファン向け（ファンレター宛先・応援メッセージ）
└ /business    お仕事のご依頼（出演・タイアップ／実績・窓口フォーム）★新設
```

- 再編の狙い：情報系3区画（NEWS/INFORMATION/SCHEDULE）の分散を解消して迷子をなくす
- /business の新設が「外から仕事を受ける」目的の要。ベンチマークにも現行にもない差別化

## 導線設計（3本）

1. **既存ファン**：SNS投稿 → TOP（最新リリース/MV即見せ）→ 配信リンク・ライブ申込 → 次回も来る理由（更新の鮮度）
2. **新規ファン**：検索「福本大晴」→ TOP → PROFILE / MOVIE で人となり → SNSフォローで囲い込み
3. **ビジネス**：検索・紹介 → TOP の信頼感 → /business（実績・プロフィール・フォーム）→ 問い合わせ

計測：Vercel Analytics＋GA4。CTA（配信リンク/ライブ申込/フォーム送信）のクリックを計測し、月次で日報フォルダにレポート。
