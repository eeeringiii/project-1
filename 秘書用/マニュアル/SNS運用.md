# マニュアル：SNS運用（公式アカウント）

## 目的
公式SNSの更新を止めず、告知の漏れ・トンマナのブレをなくす。
SNS → HP → ライブ/FC への導線の起点（HPリニューアル計画の「導線設計」と連動）。

## 対象アカウント
- 【要確認】運用中の媒体一覧とアカウント名（X / Instagram / TikTok / YouTube など）。揃い次第ここに表で記載する

## 頻度・トリガー
- **定期投稿**：週次で翌週分の投稿案を作成（毎週◯曜【要確認】）
- **告知投稿**：リリース・出演・メディア情報が確定したら都度
- **効果測定**：月次（月初に前月分）

## 手順

### 1. 週次の投稿計画（秘書 → えりんぎさん承認）
1. 秘書が翌週の投稿案（本文・ハッシュタグ・投稿日時）を `秘書用/アイデア/` に下書き
2. えりんぎさんが承認・修正指示
3. 承認済みの案を予約投稿（予約ツール【要確認】：X予約機能 / Meta Business Suite など媒体標準を第一候補）

### 2. 告知投稿（都度）
- 情報が1件確定したら、**媒体別に一括生成**する：
  - X：速報性重視。1投稿で要点＋リンク
  - Instagram：ビジュアル必須。フィード＋ストーリーズ
  - （媒体が確定したらテンプレを追記）
- 必ずHPのNEWSと同時更新（→ `HP更新.md`）。**SNSにしかない情報・HPにしかない情報を作らない**

### 3. トンマナ・投稿ルール
- 一人称・呼称・絵文字の使い方：【要確認】既存運用のルールを聞き取りしてここに固定する
- NG事項（最低限）：
  - 未発表情報のフライング（解禁日時を必ず確認）
  - 権利物（他者の写真・音源・ロゴ）の無断使用
  - 個人情報・位置がリアルタイムで特定される投稿
- 迷ったら投稿前にえりんぎさんへ確認。**「解禁日時が明記されていない情報は出さない」が原則**

### 4. 月次効果測定
- 見る指標：フォロワー増減／投稿別インプレッション・保存数／HPへの流入（プロフィールリンクのクリック）
- 月初に前月分レポートを作成 → `秘書用/日報/` に保存し、翌月の投稿計画に1つ以上の改善を反映する

## 自動化メモ（Phase 4）
- 「情報1件 → 全媒体分の下書き自動生成 → 承認 → 予約投稿」のパイプライン化
- 月次レポートの自動集計・自動保存
- HPのNEWS更新とSNS告知の同時生成（1回の指示で両方に反映）
