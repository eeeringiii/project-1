## ルール
- **1業務1ファイル**。ファイル名は業務名そのまま（例：`案件対応フロー.md`）
- 各マニュアルの構成は共通：**目的 → 頻度・トリガー → 手順 → テンプレ文面 → 自動化メモ → 更新履歴**
- えりんぎさんの確認が必要な未確定事項は **【要確認】** マークで明示する
- 業務のやり方が変わったら、その場でマニュアルを直す（マニュアルが常に正）
