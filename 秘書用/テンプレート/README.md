# テンプレート

Obsidian の「テンプレート」コア機能から挿入するひな形を置くフォルダです。

| テンプレート | 使う場面 | 挿入方法 |
| --- | --- | --- |
| `日報テンプレート` | その日の記録 | 左メニューの「今日のノートを開く」で自動挿入 |
| `タスクテンプレート` | 新しいタスク | コマンドパレット →「テンプレートを挿入」 |
| `アイデアテンプレート` | 思いつき・SNS下書き | コマンドパレット →「テンプレートを挿入」 |

- `{{title}}` はファイル名、`{{date:YYYY-MM-DD}}` は日付に自動で置き換わります
- 見出しの構成は `秘書用/秘書設定.md` の保存ルールに合わせています。変えるときは両方そろえてください
