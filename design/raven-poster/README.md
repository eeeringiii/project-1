# RAVEN / ONE MAN LIVE ポスター — Illustrator編集可能ハイブリッドSVG

`raven-poster.svg` は元ポスターをデザインカンプとして再構成した **ハイブリッドSVG** です。
写真以外のすべて（白背景・赤ライン・罫線・装飾・ブラシ・文字）がベクター／SVGテキストで、
Illustratorで個別に編集できます。

- アートボード: **1043 × 1500 px**（元画像と同比率）
- 形式: SVG 1.1 / Illustrator互換
- 文字: すべて `<text>`。**アウトライン化していません**
- 画像全体のPNG埋め込み・画像トレースは **一切していません**

---

## 1. Illustratorでの開き方

**必ず「ファイル → 開く」を使ってください。**
「配置（Place）」だと全体が1つのオブジェクトになり、レイヤーが展開されません。

読み込みダイアログでは以下を選びます。

| 項目 | 設定 |
| --- | --- |
| SVGの読み込み | **レイヤーを維持 / Import as Editable** |
| 画像リンク | リンク（埋め込みにしない） |

レイヤー名・オブジェクト名は `data-name` 属性（日本語）に入れてあり、
Illustratorはこれをレイヤー名として読み取ります。

---

## 2. 写真の配置（重要）

**元画像のピクセルデータは手元にないため、写真は「リンク画像」の枠として組んであります。**
以下の2ファイルを `images/` に入れると、そのまま所定の位置・サイズで表示されます。

| リンク先 | 内容 |
| --- | --- |
| `images/raven-bg.jpg` | 背景写真（ダイナーの内装）。高解像度JPG |
| `images/raven-members.png` | 人物5人の切り抜き。**背景透過PNG** |

配置後、`写真` レイヤー内の **`写真差し替えガイド`** サブレイヤーを削除してください
（赤いハッチと案内文字が消えます）。

### 合成済みの1枚しか無い場合

`images/raven-bg.jpg` に元の合成写真を入れ、`人物` サブレイヤーを非表示または削除すれば
そのまま成立します。あとで人物を切り抜いたら `人物` に入れ直してください。

### クリッピングマスク

`背景写真` `人物` はそれぞれ独立したクリッピングマスク（`写真帯` = x0 / y452 / w1043 / h836）を
持っています。Illustratorでは以下がそのままできます。

- マスクの形を直接編集（ダイレクト選択ツール）
- マスク内で写真だけを移動・拡大縮小
- リンクパネルから写真を差し替え

## 3. レイヤー構成

```
背景
├ 白背景            白ベース / 上部白ブロック / 下部白ブロック
├ 赤ライン          赤ライン_右上 / 赤ライン_左下
└ 装飾              罫線_ONE MAN LIVE / 区切り線_左 / 区切り線_右 / 罫線_AT / 罫線_下部

写真
├ 背景写真          背景写真_画像（リンク＋マスク）
├ 人物              人物_画像（リンク＋マスク）
└ 写真差し替えガイド  ※写真を入れたら削除

装飾（前面）        金色バー / 縦組み_RAVEN

文字
├ ONE MAN LIVE
├ RAVEN            【RAVEN】
├ 2026
├ 12.21
├ AT
├ 赤羽ReNY alpha
└ ワンマンライブ決定！！

効果
├ 影                影_写真上 / 影_写真下
├ ブラシ            ブラシ_右下（筋36本＋粒20個）/ ブラシ_写真フチ
└ ノイズ            ノイズ面
```

### 「装飾（前面）」について

指定のレイヤー構成では装飾は `背景` 配下ですが、**金色バーと左端の縦組みRAVENは
写真の上に重なる**ため、`背景 > 装飾` に入れると写真の下に隠れて元画像を再現できません。
そのため写真より前面に描かれる独立レイヤー `装飾（前面）` として分離しています。
背面に置くべき装飾（罫線・区切り線）は指定どおり `背景 > 装飾` に入っています。

## 4. フォント

環境にあるフォントに置き換えて構いません。`font-family` を変えるだけで反映されます。

| 対象 | 指定 | 想定 |
| --- | --- | --- |
| 【RAVEN】/ 12.21 / 2026 / 縦組みRAVEN | `Didot, Bodoni 72, ヒラギノ明朝, 游明朝, Noto Serif JP` | ハイコントラストなディドネ系明朝 |
| ONE MAN LIVE / AT | `Helvetica Neue, Helvetica, Arial, ヒラギノ角ゴ` | 字間を広げたサンセリフ |
| 赤羽ReNY alpha | `ヒラギノ明朝, 游明朝, Noto Serif JP` | 明朝 |
| ワンマンライブ決定！！ | `ヒラギノ明朝, 游明朝, Noto Serif JP`（Bold） | 太明朝（見出し明朝） |

サイズ・字間は元画像の実測値に合わせてありますが、**フォントを差し替えると字幅が変わります。**
特に `【RAVEN】` はブラケットのサイドベアリングがフォントごとに違うため、
左端が 42px、右端が 995px に収まるよう `x` とフォントサイズを微調整してください。

## 6. 効果レイヤーの注意

- `ノイズ` は `feTurbulence` によるSVGフィルタです。Illustratorでは「SVGフィルター」効果として
  読み込まれます。不要なら **レイヤーごと非表示／削除** で構いません。
- `ノイズ` は乗算（`mix-blend-mode: multiply`）、不透明度4.5%です。
- `ブラシ` はすべて通常のベクターパスなので、色・形・本数を自由に編集できます。
