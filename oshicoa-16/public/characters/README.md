# タイプ別キャラクター画像

診断結果・タイプ詳細・トップに表示される、16タイプのキャラクターイラストを置く場所です。

## 置き方

各タイプのコードをファイル名にした画像を、このフォルダに置くだけで自動的に反映されます。

```
public/characters/RCGT.webp
public/characters/RCGS.webp
...
public/characters/CPMS.webp
```

- **ファイル名**: タイプコード（大文字）+ `.webp`。`.webp` が無ければ同名の `.png` を探し、どちらも無ければ自動で抽象ビジュアル（きらきらの円）にフォールバックします。
- **推奨サイズ**: 正方形・800〜1000px 程度。
- **背景**: 透過（PNG/WebPのアルファ）推奨。透過でなくても、淡いパステル背景なら馴染みます。
- 画像の後ろにはピンク〜パープルのふんわりした光が自動で敷かれます。
