# 友だち追加 → スプレッドシート自動追記

エルメ（L Message）に**友だち追加してきた人**を、Googleスプレッドシートへ**自動で1行追記**する仕組みです。

- 対象シート: [顧客リスト](https://docs.google.com/spreadsheets/d/1UPoW2mvBQ72tdxDVPn4AG2Pcr0QuXxt0hfrZ8ZUzbNk/edit?gid=0#gid=0)
- 追記される列: `No / LINEユーザー名 / トークルームURL` （残りの営業ステータス列は空欄のまま。手動運用の邪魔をしません）

```
[LINE友だち追加] → [エルメの友だち追加アクション] → (Webhook/URL送信) → [Apps Script Webアプリ] → [スプレッドシートに1行追記]
```

---

## 構成ファイル

| ファイル | 役割 |
| --- | --- |
| `Code.gs` | Apps Script 本体（Webアプリ）。友だち情報を受け取りシートに追記 |
| `appsscript.json` | Apps Script のマニフェスト（Webアプリ設定・タイムゾーン） |

## セットアップ手順

### STEP 1. Apps Script を作成・デプロイ

1. https://script.google.com にアクセス →「新しいプロジェクト」
2. 既定の `Code.gs` の中身を、このリポジトリの `Code.gs` の内容で**丸ごと置き換え**
3. 上部の**設定セクション**を書き換える:
   - `SHEET_ID` … 既に対象シートのIDが入っています（変更不要）
   - `OA_ID` … 既存シートのトークルームURLから採取済み（LINE公式アカウントを変えた時だけ差し替え）
   - `SECRET_TOKEN` … **必ず**長いランダム文字列に変更（例: `k7Fq2p...`）。この後エルメ側URLで使います
4. 保存（💾）
5. まず動作確認: 関数の一覧から **`testAppend`** を選んで「実行」。初回は権限承認を求められるので許可 → シートにテスト行が1行増えればOK（確認後、その行は手で削除）
6. 右上「デプロイ」→「**新しいデプロイ**」→ 歯車⚙️で種類「**ウェブアプリ**」を選択
   - 説明: 任意（例: line-friend-to-sheet v1）
   - **実行するユーザー**: 自分
   - **アクセスできるユーザー**: **全員**
7. 「デプロイ」→ 表示される「**ウェブアプリのURL**」（`https://script.google.com/macros/s/XXXX/exec`）を控える

> ⚠️ コードを直した後は「新しいデプロイ」または「デプロイを管理→編集→バージョン新規」をしないと反映されません。

### STEP 2. 叩くURLを組み立てる

エルメから叩くURLは以下の形です（`token` は STEP1 の `SECRET_TOKEN` と同じ値）:

```
https://script.google.com/macros/s/XXXX/exec?token=秘密の文字列&name=<表示名>&uid=<ユーザーID>
```

`<表示名>` と `<ユーザーID>` の部分は、**エルメの差し込みコード**で友だちの実データに置き換えます（次のSTEP）。

### STEP 3. エルメ側で「友だち追加アクション」に外部送信を設定

エルメの管理画面で、友だち追加時に上のURLを叩くよう設定します。プランやUI改定で名称が異なることがあるため、以下のいずれかの経路で「**指定URLにアクセス／Webhook送信／外部連携**」できるアクションを探してください。

- **友だち追加時アクション**（自動応答 → 友だち追加時 / あいさつ）に **アクションを追加**
- アクション種別で **「URL送信」「Webhook」「外部連携」「API連携」** 系を選択
- 送信先URLに STEP2 のURLを設定
- `name` と `uid` の値に**差し込みコード**を割り当てる:
  - `name` → 友だちの **表示名** の差し込みコード
  - `uid` → 友だちの **LINEユーザーID（UID / mid）** の差し込みコード

> 差し込みコードの正確な記法はエルメの「差し込みコード一覧」ボタンから確認できます（表示名・ユーザーID などが用意されています）。値を選ぶだけでURLに埋め込まれます。

`uid` を渡せない場合でも `name` だけで追記自体は動きます（その場合トークルームURL列は空欄になります）。

---

## もしエルメに「外部URLを叩くアクション」が無い場合（フォールバック）

プランによってはエルメから外部送信ができないことがあります。その場合は **LINE公式アカウントの Messaging API Webhook** を直接使う方法に切り替えられます（こちらは確実に友だち追加＝`follow`イベントを取れます）。

1. LINE Developers でチャネルの **Webhook URL** に STEP1 のWebアプリURL（`?token=秘密の文字列` 付き）を設定し、Webhook利用をON
2. `Code.gs` を LINE の `follow` イベント形式（`events[].type === 'follow'`、`events[].source.userId`）を読む版に拡張し、表示名は LINE の `getProfile` API で取得

> 注意: LINE公式アカウントのWebhook URLは**1つだけ**です。既にエルメがそのWebhookを使っている場合、直接方式に切り替えるとエルメ側の自動応答が止まります。**エルメを主で使うなら STEP3 の外部送信方式が第一候補**です。この切り替えが必要になったら、`Code.gs` の `follow` 対応版を用意しますので声をかけてください。

## テスト（デプロイ後の疎通確認）

ブラウザで以下を開く（`XXXX` と `秘密の文字列` は自分の値に）だけで1行追記されます:

```
https://script.google.com/macros/s/XXXX/exec?token=秘密の文字列&name=疎通テスト&uid=Utest0000000000000000000000000099
```

- 成功: `{"ok":true,"added":true,"no":66,"name":"疎通テスト"}`
- 認証NG: `{"ok":false,"error":"unauthorized"}` → `token` を確認
- 追記されたテスト行は手で削除してください

## 挙動メモ

- **重複防止**: 同じ `uid` が既にシートに居る場合はスキップ（`SKIP_DUPLICATE = true`）。ブロック解除→再追加での二重登録を防ぎます
- **No 採番**: A列の最大番号 +1 を自動採番
- **競合防止**: `LockService` で同時追記を直列化
- 営業・面談・契約などのステータス列は**空欄**で追加（既存の手動運用フローに合わせています）
