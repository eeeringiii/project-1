# 初回企画 10本＜A案・エイゴのセンパイ＞

作成：2026-07-25 ／ 担当：カン
共通フォーマット：0-3秒フック → ボケ（直訳/勘違い）→ センパイがバッサリ正解 → 一覧まとめ → CTA
演者：固定1名の1人2役（生徒＝ボケ／センパイ＝ツッコミ）。縦型〜40秒。

各企画の項目：入口テーマ／ターゲット／フック(冒頭3秒)／中身／オチ／CTA／想定PF／尺／注意

---

## ◎推奨から着手したい5本（新規獲得・爆発枠）

### 01.「全米が泣いた」って英語でなんて言う？
- 入口テーマ：映画（あるある突っ込み）
- ターゲット：映画好き・英語無関心層まで広め
- フック：「"全米が泣いた"って、英語でなんて言うか知ってる？」
- 中身：生徒「All America cried…?」と直訳 → センパイ「言わんて」。実際の宣伝コピー表現（例："critically acclaimed" 的な言い回し）を紹介。
- オチ：「そもそも全米、泣いてない」でバッサリ。
- CTA：「他の"盛り"日本語、英語で知りたい人コメントで」
- 想定PF：IG-R / TT / YT-S
- 尺：30秒
- 注意：特定映画のロゴ・映像は使わない（一般論として）。

### 02. このポケモン、英語でなんて言う？
- 入口テーマ：ゲームIP
- ターゲット：ゲーム/アニメ層（英語外の巨大母数）
- フック：「このポケモン、英語名わかる人～？」
- 中身：日本語名 → 英語名の意外さ（意味が透ける命名）を3体テンポよく。
- オチ：最後の1体が原型なさすぎてセンパイも噛む。
- CTA：「次やってほしいIGコメントで」＋一覧保存誘導
- 想定PF：TT / IG-R / YT-S
- 尺：35秒
- 注意：**キャラ画像・音源は使わず、名前クイズ（テキスト/口頭）で構成**。ネタバレ・素材使用はグレーなので固有画像NG。

### 03. 関西人の「知らんけど」を英語に直訳したら
- 入口テーマ：方言（言語差）
- ターゲット：関西・方言ネタ好き（拡散力高）
- フック：「関西人の"知らんけど"、英語でどう訳す？」
- 中身：生徒「I don't know but…」直訳 → センパイが会話のニュアンス（責任回避のやわらげ）に合う自然表現を提示。
- オチ：「"知らんけど"は文法ちゃう、生き方や」で締め。
- CTA：「あなたの地元の"訳せない方言"募集」
- 想定PF：TT / IG-R
- 尺：30秒
- 注意：方言の当事者いじりにならないよう愛のあるトーンで。

### 04. スタバの"呪文"、全部英語で言える？
- 入口テーマ：日常ネタ
- ターゲット：カフェ/日常層・女性多め
- フック：「スタバのあの長い注文、英語で言えたら勝ち」
- 中身：生徒がカタカナ丸暗記で撃沈 → センパイが実際の注文フレーズをテンポよく。
- オチ：最後に「サイズ言い間違えてる」オチ。
- CTA：「海外で使える"注文英語"、一覧保存してね」
- 想定PF：IG-R / TT
- 尺：35秒
- 注意：特定チェーンのロゴ・商標を大写しにしない。

### 05. 学校で習った英語、ネイティブは使いません
- 入口テーマ：常識破壊（言語差）
- ターゲット：英語やり直し層・幅広い
- フック：「"How are you? — I'm fine, thank you."、これ実は…」
- 中身：教科書表現3つ → センパイが「今どき言わん」と自然な返しに置換。
- オチ：「習ったの、なんやったんや」で共感オチ。
- CTA：「他に"習ったけど使わない英語"知りたい人フォロー」
- 想定PF：IG-R / TT / YT-S
- 尺：30秒
- 注意：断定しすぎず「カジュアルでは」など文脈を添える。

## ○ ストックの5本（バリエーション確保）

### 06.「死亡フラグ」って英語でなんて言う？
- 入口テーマ：若者言葉（言語差）
- ターゲット：アニメ/ドラマ層
- フック：「"死亡フラグ"、英語にあると思う？」
- 中身：直訳の迷走 → 実際に近い表現（"jinx" 的なニュアンス）を紹介。
- オチ：「このオチ自体が死亡フラグ」メタ落ち。
- CTA：コメントで次のスラング募集
- 想定PF：TT / IG-R ／ 尺：30秒
- 注意：なし

### 07. ネイティブが1日100回使う"神フレーズ" TOP3
- 入口テーマ：ランキング（お役立ち）
- ターゲット：英語やり直し・保存狙い
- フック：「これ知らないと会話止まる、神フレーズTOP3」
- 中身：3位→1位の順で、生徒の硬い言い方をセンパイが置換。
- オチ：1位が拍子抜けするほど簡単。
- CTA：**一覧まとめ保存**を強調
- 想定PF：IG-R / YT-S ／ 尺：35秒
- 注意：なし

### 08. 日本語の「一文字名詞」、英語だと長すぎ問題
- 入口テーマ：言語差おもしろ
- ターゲット：言葉好き・海外フォロワーも取れる
- フック：「"間(ま)"って英語で1単語で言える？」
- 中身：木/間/縁など一文字語 → 英語だと説明的に長くなる対比。
- オチ：「日本語、省エネすぎ」で締め。
- CTA：「他に訳しにくい日本語ある？」
- 想定PF：IG-R / TT ／ 尺：35秒
- 注意：海外向けに英語テロップ併記を検討（Cフォーマット横展開の布石）。

### 09. 空耳で覚える英語（そら耳ハック）
- 入口テーマ：言語ハック（空耳）
- ターゲット：暗記が苦手な層・拡散向き
- フック：「"掘った芋いじるな" が英語に聞こえたら勝ち」
- 中身：有名空耳3連発 → 実際の意味とセンパイの発音。
- オチ：最後の空耳が下ネタ寸前でセンパイ困る。
- CTA：「あなたの知ってる空耳英語コメントで」
- 想定PF：TT / IG-R ／ 尺：30秒
- 注意：下ネタは寸止め、品位を保つ。

### 10.【CV導線】センパイの正体、実は英会話の先生でした
- 入口テーマ：自校紹介（CV導線）
- ターゲット：ファン化した既存フォロワー→体験レッスン
- フック：「毎回バッサリ訂正するこの先輩、何者？」
- 中身：メイキング風に舞台裏 → 実はイーオンの現場・レッスンの雰囲気をチラ見せ。
- オチ：「無料体験、こっそりリンク置いときます」自然な誘導。
- CTA：**プロフィール/Storiesの無料体験リンク**へ送客
- 想定PF：IG-R → IG-S（Stories受け）
- 尺：40秒
- 注意：宣伝色を出しすぎない。10本に1本の頻度で。営業感より"中の人紹介"のトーンで。
