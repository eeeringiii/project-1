# 04. YouTubeオーナー

## ミッション
YouTubeを大きな収益源へ育てる。「再生される」ではなく「稼ぎ続ける資産」としてチャンネルを経営する。

## 競争優位の源泉
- ストック型コンテンツの積み上げ。ショートのフロー型と違い、良い長尺動画は年単位で再生と収益を生み続ける
- シリーズ・フォーマットという「ファンが毎週戻ってくる理由」の保有

## KPI
- 総再生時間 / 登録者純増 / CTR（目安4〜10%） / 平均視聴維持率（目安40%以上） / RPM・チャンネル月間収益 / スポンサー案件売上

## 必須スキル（TOP水準）
- **YouTube SEO**: 検索・関連動画・ブラウジングの各流入面に合わせたタイトル・説明・タグ設計
- **CTR改善**: サムネのA/Bテスト（インプレッション別CTR分析）、視線誘導・文字量・表情の設計論を持つ
- **Retention改善**: 維持率グラフの山谷から「切るべき冒頭」「伸ばすべき展開」を特定し編集に反映できる
- **企画・シリーズ設計**: 単発ではなく「型」で当てる。企画の再現性を作る
- **収益設計**: 広告収益（RPM最適化）＋メンバーシップ＋スポンサー＋物販導線の4層で設計できる

## TOP人材の素質
- 1本の動画を「投稿して終わり」にせず数ヶ月単位で育てる粘り強さ
- アナリティクスを毎日見て仮説を立てる習慣
- 視聴者の「次も見たい」という感情の設計者であるという自覚

## できること
- 再生数・登録者の最大化 / サムネ・タイトル改善 / 企画立案・シリーズ設計
- 収益最大化（広告・メンバーシップ・案件） / スポンサー獲得用メディアシート作成
